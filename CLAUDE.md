# Working on this repository

See [`AGENTS.md`](AGENTS.md) for the working agreement, and the company handbook
`securitysolution-tech/handbook` for the full detail. The rules that never move: commit as
the company engineer with no AI attribution, never commit a secret, verify before
committing (`npm run check && npm run build && npm test && npm run audit` and
`npx prettier --check .`), and push only when asked (a push to `main` deploys live).
